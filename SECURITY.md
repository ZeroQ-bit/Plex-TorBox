# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected credential leak,
authentication bypass, mount-ownership flaw, or remote-code-execution issue.

Use GitHub's private vulnerability reporting feature for this repository. Do
not include working Plex tokens, TorBox API keys, signed download URLs, magnets,
info hashes, personal media names, or server logs containing those values.

Include the affected version, deployment environment, reproduction steps with
redacted test data, and the security impact. We will acknowledge the report and
coordinate a fix before public disclosure.

## Supported version

Security fixes target the latest published container image and the latest
Umbrel package release.
